`@fieldnotes/react` mounts a board with the `<FieldNotesCanvas>` component and needs React 18 or 19. `initialData` takes a saved board, and `onChange` receives the board state after a change, debounced by 250ms by default.

The [`@fieldnotes/react` README](https://github.com/IrakliDevelop/fieldnotes/blob/master/packages/react/README.md#quick-start) has the full setup.
