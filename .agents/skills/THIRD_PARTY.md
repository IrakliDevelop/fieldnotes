# Third-party skill sources

Some skills in this directory adapt material from other repositories. Field Notes skills adapt the
Pollyroll adaptations of these sources. Each adapted skill names its source in its first paragraph.
Notices required by the source licenses follow.

## Guidance paraphrased, not copied

`fieldnotes-concise-code` restates ideas from Anthropic's prompting best practices ("minimize
overengineering") and forrestchang/andrej-karpathy-skills `karpathy-guidelines` in its own words. No
text from either is reproduced.

`fieldnotes-typescript` paraphrases checks from Anthropic `claude-plugins-official`
`pr-review-toolkit` agents `type-design-analyzer` and `silent-failure-hunter` (Apache-2.0). No text is
reproduced.
